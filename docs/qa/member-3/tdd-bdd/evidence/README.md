# TDD/BDD Evidence

The RED, GREEN, REFACTOR, and Cucumber command outputs are captured as text
logs in this folder. No screenshots were captured automatically. If screenshot
evidence is required, run the exact commands in the parent
`test-evidence.md`, capture the real terminal output, and save the images here
as `red-stage.png`, `green-stage.png`, `refactor-stage.png`, and
`cucumber-run.png`. Do not create screenshots from reconstructed output.
