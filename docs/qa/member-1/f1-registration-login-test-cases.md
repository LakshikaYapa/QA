# F1 — Registration and Login Test Cases

**Execution date:** 2026-11-25
**Environment:** Local React/Vite frontend at `http://127.0.0.1:5173`, Windows host, Node.js 26.13.1, npm 11.20.0; integrated browser version not exposed. Limited API validation checks used the local Express server with a temporary loopback-only TCP stub, not a MongoDB service or database. No account or real credential was used.

## Confirmed feature inventory

Registration and login pages and API handlers exist. Registration requires name, email, password; the client shows/enforces password rules, and the backend checks password strength and duplicate email. Login validates required fields and submits to the login API. JWT authentication and a protected profile route exist. A client-side logout action exists. No password-reset flow or role-based behavior was found in the inspected client, server routes, or user schema. See the limitations and evidence in the report.
